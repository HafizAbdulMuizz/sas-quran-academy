# 🕌 SAS Online Quran Academy

A modern full stack Quran Academy website built with Next.js, MongoDB Atlas and Tailwind CSS.

## 🚀 Features

* Online Admission Form
* MongoDB Atlas Database
* Admin Authentication
* Protected Admin Dashboard
* Approve Admissions
* Delete Admissions
* Search Students
* Course Filters
* CSV Export
* Responsive Design
* Modern Islamic UI

## 🛠️ Tech Stack

### Frontend

* Next.js
* React.js
* Tailwind CSS

### Backend

* Next.js API Routes
* MongoDB Atlas
* Mongoose

### Deployment

* Vercel

## 🌐 Live Demo

https://sas-quran-academy.vercel.app/

npm run dev
